# W02 — road-trip

## Project Identity

Mobile-first road trip photo sharing app (ASP.NET Core 8.0 Minimal API + EF Core 8.0 + Azure SQL + Azure Blob Storage + MapLibre GL JS v5.21.0 + Vanilla JS/HTML/CSS). Has an iOS hybrid shell via Capacitor 8 + SPM, never CocoaPods. Hosted on Azure App Service (Docker/container deploy), dedicated SQL instance `sql-roadtripmap-prod` / DB `roadtripmap-db`, shared blob/ACR with stock-analyzer. CLAUDE.md last verified 2026-05-10. Active development on `develop` and feature branches; main is production-protected.
