# W01 — stock-analyzer

## Project Identity

ASP.NET Core (.NET) web application for stock market analysis. Backend: C# minimal API + `StockAnalyzer.Core` (EF Core, Azure SQL). Frontend: Vanilla JS + Plotly.js. Companion WPF desktop loader (`eodhd-loader`) populates the database via iShares ETF constituent data and EODHD price feeds. Deployed via Docker + GitHub Actions to Azure App Service at `psfordtaurus.com`. Current branch: `develop`.
