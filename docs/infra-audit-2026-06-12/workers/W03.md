# W03 — photo-portfolio

## Project Identity

Static photography portfolio with owner-only admin SPA. Public feed + admin SPA deploy to Cloudflare Workers via `wrangler deploy`; privileged work (upload, image processing, manifest writes, GitHub OAuth) runs in a standalone Azure Functions app (`api/`). Storage is Azure Blob with managed identity (no account keys). Auth is self-hosted GitHub OAuth -> signed session JWT. Current branch: `main` (latest commit: `858f20d` — post-publish cache-buster fix). Stack: TypeScript 5.6 strict, Astro 5, Azure Functions Node v4, Sharp, Vitest + Playwright.
